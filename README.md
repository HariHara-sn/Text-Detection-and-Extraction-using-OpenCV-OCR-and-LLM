# OCR and OpenCV – Text Detection and Extraction

## Overview

This project demonstrates a simple implementation of **Optical Character Recognition (OCR)** using **OpenCV** and **Tesseract OCR**. It detects text in images, extracts the textual content, and visualizes detected text regions using bounding boxes.

The project is intended as a **baseline OCR extraction pipeline**, which can be extended for domain-specific use cases such as medical prescription analysis.

---

## Features

* Load and preprocess images using OpenCV
* Convert images to grayscale for better OCR performance
* Extract text from images using Tesseract
* Draw bounding boxes around detected words
* Simple and extensible Python-based implementation

---

## Tech Stack

* Python
* OpenCV
* Tesseract OCR
* PyTesseract
* Matplotlib
